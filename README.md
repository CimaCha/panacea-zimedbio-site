# ZyMedBio — сайт для сценария «Панацея»

Локальный игровой сайт компании ZyMedBio для настольной ролевой игры «Зов Ктулху».

## Запуск

Передайте только `index.html` и откройте его двойным щелчком в современном браузере. Стили, скрипт и значок вкладки уже встроены в файл; интернет и установка зависимостей не нужны.

Заявка на лечение демонстрационная: заполненные данные не отправляются и не сохраняются. Карта Далласа и план центра условные и встроены в страницу.

## Публикация через GitHub Pages

1. После слияния PR в `main` откройте репозиторий на GitHub и перейдите в **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь завершения публикации. Ссылка на сайт появится в разделе **Pages**. Для этого репозитория она будет иметь вид `https://cimacha.github.io/panacea-zimedbio-site/`.

Сайт останется доступным без сервера и сборки. При публикации игровой код терминала и тексты закрытого архива можно будет увидеть в исходном коде страницы.

## Для ведущего

Кнопка «Служебный доступ» закреплена справа внизу экрана. Команды `help` и `scan` дают подсказки; код `ZMB-17B` указан в паспорте исследования Zylactis. Команда `auth ZMB-17B` показывает предупреждение о попытке взлома и открывает четыре оригинальных игровых документа с намёками, не раскрывающими развязку. Поскольку сайт статический, эти документы также доступны через исходный код страницы.
